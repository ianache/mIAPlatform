**pyproject.toml:** Add `"bullmq>=2.20.0"` to dependencies. Run `uv sync` to install.

**src/backend/api/library.py — add three new endpoints:**

1. **POST /flows/{flow_id}/execute** (status_code=202):
   - Verify flow exists for tenant (404 if not)
   - Create mia.flow_runs row via raw SQL INSERT (status='running', trigger='manual')
   - Parse Redis connection from settings.REDIS_URL: extract host as settings.REDIS_URL.split("://")[-1].split(":")[0]; port=6379; password=settings.REDIS_PASSWORD
   - Create BullMQ Queue("execute_flow", connection={host, port, password}) and call await queue.add("execute_flow", {"flowId": str(flow_id), "tenantId": tenant_id, "runId": run_id})
   - Call await queue.close() after adding the job
   - Return {"run_id": run_id, "status": "running"}

2. **GET /flows/{flow_id}/runs** (paginated list):
   - Query mia.flow_runs WHERE flow_id = flow_id AND tenant_id = tenant_id ORDER BY started_at DESC LIMIT 50
   - Return list of run objects (id, status, trigger, started_at, finished_at, final_output — exclude full log to keep response small)

3. **GET /flows/{flow_id}/runs/{run_id}** (single run with full log):
   - Query single flow_run, verify tenant ownership
   - Return full object including log JSONB array

4. **WebSocket WS /library/runs/ws/{run_id}** (new WebSocket endpoint):
   - Authenticate via query param ?token= using verify_token_raw from security.py
   - Accept WS connection: await event_manager.connect("run:" + run_id, websocket)
   - Keep alive: async for _ in websocket.iter_text(): pass (or keepalive loop)
   - On disconnect: event_manager.disconnect("run:" + run_id, websocket)
   - IMPORTANT: namespace key is "run:{run_id}" (not bare run_id) to avoid collision with chat sessions that use bare session_code keys

5. **Redis subscriber task** (background task started at app startup):
   - In main.py lifespan, after init_redis, start asyncio task for subscribe_flow_run_events()
   - subscribe_flow_run_events(): use redis.asyncio to SUBSCRIBE "flow_run:*" (pattern subscribe)
   - On message: parse JSON, extract run_id from channel name "flow_run:{run_id}", call await event_manager.broadcast("run:" + run_id, event)
   - Also: update mia.flow_runs status/finished_at when event type is "run_complete" or "run_failed"

Note: For the Redis subscriber, use `aioredis` or `redis.asyncio` (already in pyproject.toml as redis[hiredis]). Do NOT use the bullmq connection for pub/sub — keep a separate pubsub connection.
